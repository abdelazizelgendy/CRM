# قواعد ربحية العقد

`Budgeted Margin = Current Contract Value − Current Cost Budget`.

`Operational Margin = Customer Invoices Issued Internally − Recognized Operational Cost`.

`Forecast EAC = Recognized Operational Cost − Reversals + Forecast ETC`، و`Forecast Margin = Current Contract Value − Forecast EAC`.

لا تجمع العملات ولا تستخدم التكلفة السرية دون `profitability.view_sensitive`. Collection Context ليس صافي تدفق نقدي.
