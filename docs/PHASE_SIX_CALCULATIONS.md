# الحسابات والتقريب

الأموال `bigint` Minor Units، والكميات أجزاء من ألف. أساس البند = تقريب نصف لأعلى لـ`unitPriceMinor × quantityMills / 1000`. الخصم ثم الضريبة يحسبان Basis Points وبالتقريب نفسه، ثم الرسوم. الرصيد = إجمالي الفاتورة + Debit − Credit − التوزيعات النشطة. العملات 0/2/3 منازل تنسق منفصلة ولا توجد أسعار صرف أو جمع عملات. لا يعرض DSO لعدم تعريف مصدر وفترة محاسبية موثوقين.
