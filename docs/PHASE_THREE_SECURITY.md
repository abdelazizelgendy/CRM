# أمان صندوق المحادثات

- كل سجل تشغيلي يحمل `organizationId`، وكل عملية تتحقق من الشركة والفاعل والصلاحية.
- الوصول إلى معرف محادثة من شركة أخرى يرفض بـ`CROSS_TENANT`.
- المشاهد لا يستطيع الرد أو الإسناد أو التغيير أو كتابة ملاحظة.
- مفاتيح Idempotency تمنع الرد المكرر، والقوالب والرسائل تنظف من `<` و`>` ولا تنفذ HTML.
- الملاحظات `internal` منفصلة عن الردود الصادرة، ولا يوجد حذف نهائي.
- Local Provider محظور في Production افتراضيًا، ولا يحتوي Seed على بيانات حقيقية.
- Migration لا يضيف سياسات كتابة مباشرة؛ الربط النهائي يحتاج RPCs تفحص `auth.uid()` ولا تقبل `organization_id` من المتصفح.

المرفقات في الواجهة محاكاة فقط. العقد المستقبلي يقيد الحجم بـ10MB ويجب إضافة allowlist للأنواع وفحص برمجيات خبيثة قبل التفعيل.
