# المعاينة والقوالب

المسار `/dashboard/sales/quotations/q-1/preview` يقدم HTML/Print A4 ثنائي اللغة، مع بيانات الشركة والعميل والإصدار والبنود والإجماليات والشروط والتذييل والعلامة المائية. CSS يمنع قطع الأقسام ويكرر رأس الجدول.

هذه ليست خدمة PDF Server-Side. يمكن اختيار Print/Save as PDF من المتصفح؛ لم يُدّع اختبار مكتبة توليد PDF على الخادم.

القالب يقبل المتغيرات الموثقة فقط. أي متغير غير مسموح يزال، ولا توجد قوالب JavaScript. التكلفة والهامش غير موجودين في قائمة متغيرات العميل.

المعاينة تقرأ الإصدار الحالي من Local Repository، وتخفي البنود الاختيارية غير المحددة. ترقيم الصفحات الدقيق متعدد الصفحات محدود بقدرات HTML Print في المتصفح.
