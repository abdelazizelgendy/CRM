# موافقات المرحلة الخامسة

لكل إصدار عقد Approval مستقل. الانتقال إلى Under Review يمنع التحرير. الرفض/طلب التعديل يتطلب تعليقًا، ولا يعتمد مقدم الطلب سجله. عند اعتماد إصدار جديد تتحول الإصدارات السابقة Approved/Active إلى Superseded. Change Order له دورة مستقلة ولا يغير القيمة أو المدة قبل Approved ثم Applied مرة واحدة.
