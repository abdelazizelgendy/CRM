# دورة أمر الإنتاج

Draft → Planned → Material Check → Awaiting Approval → Released → In Progress/On Hold → Partially Completed → Completed → Closed. الإلغاء قبل Release فقط. Release يتطلب snapshots معتمدة وMaker-Checker. لا يعدل الأمر Released في الحقول المؤثرة، ولا يغلق بعمليات مفتوحة، ولا يحذف بعد حركة مرحلة.
