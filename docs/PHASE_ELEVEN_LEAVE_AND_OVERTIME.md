# الإجازات والعمل الإضافي

أنواع الإجازة إعدادات شركة وليست محرك التزام قانوني. Manager ثم HR قبل الاستهلاك. Leave Ledger immutable، رصيده مشتق، ويدعم reversal واحدًا وadjustment بـMaker-Checker. Overtime يحتفظ بالدقائق والمراجع فقط، يمنع التداخل ولا يعتمد قبل مطابقة الحضور؛ لا يحسب أجرًا أو مبلغًا.
