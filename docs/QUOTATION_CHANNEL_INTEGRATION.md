# تكامل قنوات عرض السعر

الموجود هو `dispatchDemo` فقط لقنوات Email Demo وWhatsApp Demo وManual Delivery. يتحقق من المدخلات، ويمنع التكرار عبر Idempotency Key، ويسجل المنفذ والوقت والإصدار والحالة وسبب الفشل التجريبي.

لا توجد Tokens أو SMTP أو اتصال خارجي. لا يتحول العرض إلى Sent إلا إذا نجحت المحاكاة. التكامل المستقبلي يحتاج Outbox/Queue، توقيع Webhook، Retry محدود، Provider Message ID، تشفير الأسرار، وحالة تسليم قابلة للتدقيق.

الإرسال التجريبي الفاشل يبقى مسجلًا كـ`failed` ولا يغير العرض إلى Sent، وتكرار Idempotency Key يعيد السجل نفسه دون إرسال مكرر.
