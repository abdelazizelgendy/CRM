# التكلفة التشغيلية

المخطط = BOM snapshot material + planned work-center/resource. الفعلي = Inventory Issue cost snapshots بعد المرتجعات + actual resource + subcontract + rework. Cost per good unit لا يحسب عند صفر Good. العملات لا تخلط. Issue هو مصدر الاعتراف المادي؛ Finished Receipt لا يكرر Cost Event المشروع. هذه تكلفة تشغيلية وليست Inventory/Production/WIP/Standard Cost Accounting ولا تنشئ GL أو Journal Entries.
