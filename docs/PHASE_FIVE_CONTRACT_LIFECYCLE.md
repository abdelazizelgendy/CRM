# دورة حياة العقد

`Draft → Under Review → Changes Requested/Approved → Active → Suspended/Completed/Terminated/Expired`، مع `Cancelled` قبل التنفيذ و`Superseded` للإصدار السابق بعد اعتماد الجديد. الانتقالات معرفة مركزيًا في `domain.ts` ولا يمكن القفز من Draft إلى Active. الإكمال يتطلب المخرجات الإلزامية مكتملة أو متجاوزة بمسار موثق.
