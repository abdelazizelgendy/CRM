# دورة حياة الفاتورة

`draft → under_review → approved → issued` مع `changes_requested` أو الرجوع من الرفض إلى Draft، و`voided` بصلاحية وسبب. الإنشاء يتم من مصدر عقد مؤهل مرة واحدة ويحفظ Snapshot للعقد ونسخته والعرض والطلب والعميل والعملة والبنود والمراجع. لا تعدل Issued، ولا يتم إصدارها دون اعتماد منفصل. Workflow وSettlement وDelivery حالات مستقلة.
