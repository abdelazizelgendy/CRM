# نموذج بيانات المرحلة الخامسة

الجذر `contracts` ويحفظ مرجع العرض/إصداره/طلب المبيعات/العميل وقيمة العقد، بينما `contract_versions` يحفظ Snapshots غير قابلة للتعديل بعد الاعتماد. تتبعها الأطراف والأقسام والمخرجات والمراحل والدفعات والالتزامات والمرفقات والموافقات. الأوامر التغييرية تحفظ before/after snapshot ولا تطبق قبل الاعتماد. أوامر العمل تتبع العقد والمخرج/المرحلة ولها مسندون وChecklist وأنشطة.

القيم المالية في التطبيق Minor Units بـBigInt، وفي عقد PostgreSQL `numeric(20,3)`. كل الجداول الحساسة تحمل `organization_id`، مع مفاتيح مركبة وفهارس الحالة والاستحقاق وSoft Delete.
