# تقرير التحقق — المرحلة الأولى

## اختبارات آلية داخل المستودع

| الاختبار | الأمر | النتيجة |
|---|---|---|
| Lint | `npm run lint` | ناجح — دون أخطاء |
| TypeScript | `npm run typecheck` | ناجح — دون أخطاء |
| وحدات الأمان | `npm test` | ناجح — 4/4 |
| Build إنتاجي | `npm run build` | ناجح — 16 مسارًا تم بناؤها |
| Smoke test | تحميل `/login` عبر خادم الإنتاج المحلي | ناجح — ظهرت عناصر الواجهة العربية الأساسية |

## اختبارات تكامل Supabase المطلوبة بعد إضافة المفاتيح

| السيناريو | معيار النجاح |
|---|---|
| إنشاء شركة | إنشاء الشركة والمالك والأدوار في معاملة واحدة |
| دخول/خروج/استعادة | الجلسة تنشأ وتنتهي والمسار المحمي يعيد التوجيه |
| عزل شركتين | استعلامات الشركة أ لا تعيد أي صف للشركة ب، حتى مع UUID معدل |
| الدعوة | رمز أحادي الاستخدام، البريد مطابق، والانتهاء بعد 72 ساعة |
| قبول مرتين | المحاولة الثانية مرفوضة لأن الحالة لم تعد pending |
| إيقاف مستخدم | العضوية غير النشطة لا تجتاز `is_org_member` |
| رفع الصلاحية ذاتيًا | RLS يرفض تعديل user_roles للمستخدم نفسه |
| حماية المالك | RLS يرفض إيقاف أو تغيير دور المالك الأساسي |
| المشاهد | لا يملك أي سياسة كتابة |

هذه السيناريوهات لا يمكن تنفيذها ضد خدمة حقيقية دون URL ومفاتيح مشروع Supabase مخصص للاختبار. الكود وMigration يجهزانها، لكن يجب تشغيلها قبل اعتماد بيئة الإنتاج.
