## اختبارات التكامل الجاهزة ولم تُنفذ

الملف `scripts/phase-two-integration.mjs` جاهز للتشغيل ضد مشروع Supabase اختبار فقط، ويغطي:

- إنشاء Lead حقيقي.
- عزل شركتين ومنع القراءة المتقاطعة.
- منع IDOR عند محاولة تعديل UUID لشركة أخرى.
- كشف التكرار بالبريد.
- تحويل Lead ومنع التحويل للمرة الثانية.

لم تُنفذ هذه الاختبارات لأن البيئة لا تحتوي URL/Anon وحسابي اختبار لشركتين، ولا يتوفر Docker لتشغيل Supabase محليًا. لم يتم تصنيفها كناجحة، ويجب إبقاء Pull Request في وضع Draft حتى تشغيلها.

## اختبارات قبول مطلوبة على مشروع الاختبار

- تطبيق Migrations المراحل الثلاث وSeed التطوير دون خطأ SQL.
- صلاحيات كل دور، خصوصًا Viewer وSales Agent.
- دمج سجلين مع بقاء التفاعلات والوسوم وأرشفة المكرر.
- استيراد CSV بخيارات التخطي والتحديث والإنشاء وتقرير الرفض.
- التحويل لفرد ولشركة والتحقق من Customer وContact ومرجع Lead.
- RTL وLTR والكمبيوتر والجوال وتبديل اللغة وحالات Empty/Loading/Error باستخدام جلسة حقيقية.
- عدم وجود أخطاء Console أثناء دورة Lead الكاملة.
