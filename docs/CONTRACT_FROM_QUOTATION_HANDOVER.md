# تسليم العرض إلى العقد

يشترط مصدرًا حالته `accepted_demo` وطلبه `won`. يحفظ العقد رقم وإصدار العرض وSales Request والعميل والبنود الأساسية والبنود الاختيارية المقبولة فقط، والنطاق والشروط والقيمة والعملة. لا تنقل التكلفة أو هامش الربح. يمنع عقدان أصليان لنفس إصدار العرض، وتدعم العملية Idempotency.
