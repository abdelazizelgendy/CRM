# نطاق المرحلة الخامسة

تنفذ المرحلة العقود من Snapshot عرض مقبول تجريبيًا وطلب مبيعات فائز، ثم الإصدارات والموافقات والأوامر التغييرية وأوامر العمل والتقويم والطباعة HTML. لا تشمل توقيعًا قانونيًا، قبولًا قانونيًا، فواتير، تحصيلًا، دفعًا، إرسالًا خارجيًا، رفع ملفات إنتاجيًا، أو نشرًا إنتاجيًا.

البيانات الحالية Local Adapter صناعية داخل الذاكرة وتُعاد بضبط الجلسة/إعادة تشغيل التطبيق. لا تستخدمها كقاعدة بيانات إنتاجية.
