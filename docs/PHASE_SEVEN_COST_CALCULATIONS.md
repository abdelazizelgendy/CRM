# حسابات التكلفة

الأموال BigInt Minor Units والكميات Mills. الترتيب على مستوى السطر: `Quantity × Unit Price` ثم خصم السطر ثم الضريبة ثم الرسوم، مع Round Half Up. الشحن مستوى مستند.

الالتزام المفتوح هو الجزء غير المعترف به من أوامر الشراء. الاستلام وحده لا يكرر الالتزام. فاتورة المورد المعترف بها أو المصروف المعترف به ينشئ Cost Event واحدًا؛ العكس Event مقابل لا حذف.

لا يستخدم JavaScript `Number` للقيم المالية الحساسة. التنسيق يدعم عملات 0 و2 و3 منازل.
