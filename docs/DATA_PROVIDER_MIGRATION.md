# الانتقال بين مزودي البيانات

- `DATA_PROVIDER=local`: تشغيل تجريبي بلا خدمات. Seed يعاد عند إعادة تشغيل الخادم/تحديث الصفحة؛ ليس مخزنًا دائمًا.
- `DATA_PROVIDER=supabase`: يبقي المصادقة ووحدات المرحلتين الأولى والثانية على Supabase. صندوق المرحلة الثالثة يرمي خطأ Stub حتى تنفيذ RPCs في مرحلة الربط.
- لا تعدل الصفحات عند إضافة مزود؛ نفذ `InboxRepository` ثم اختره في Composition Root.
- لا تستخدم `ALLOW_LOCAL_DATA_IN_PRODUCTION=true` في نشر حقيقي. وجوده مخصص لبيئات معاينة معزولة صراحةً.

خطوات الربط المستقبلية: تطبيق Migration 004 على مشروع اختبار، تنفيذ RPCs للكتابة، توصيل Adapter، تشغيل اختبارات شركتين وRLS، ثم تفعيل Supabase Provider.
