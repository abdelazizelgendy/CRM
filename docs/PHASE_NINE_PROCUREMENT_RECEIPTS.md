# تسليم المشتريات إلى المخزون

`Purchase Order → Procurement Receipt → Quality result → Stock Receipt Posting`.

Procurement Receipt لا يزيد الرصيد وحده. Stock Receipt Posting يتطلب استلام مشتريات معتمدًا وكمية غير مرفوضة ويمنع Posting المكرر. Supplier Bill لا تزيد الكمية، وStock Receipt ليست فاتورة مورد ولا تغيّر Commitment.
