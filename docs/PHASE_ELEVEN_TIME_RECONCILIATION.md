# تسوية الوقت

المصادر: Attendance worked minutes، Timesheets، Job Card labor minutes، Leave وOvertime المعتمدان. Attendance لا يساوي productive time. عند ارتباط Job Card بمهمة مشروع تخصم دقائق الربط من التجميع لتجنب التحميل المزدوج. تظهر unallocated/overallocated/missing حتى التسوية أو override مدقق؛ لا ينشأ Cost Event.
