# مواد الإنتاج

كل Production Job يمكن ربطه بقائمة متطلبات مواد بسيطة، وليس BOM/MRP كاملًا. الجاهزية تعتمد على Requested، Approved، Reserved، Issued، Shortage وRequired Date. لا تعتبر الوظيفة جاهزة إذا كانت المواد الإلزامية غير متاحة أو غير مصروفة؛ Override يحتاج سببًا وصلاحية ولم يُفعّل كاعتماد تلقائي.
