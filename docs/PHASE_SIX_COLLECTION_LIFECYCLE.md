# دورة حياة التحصيل

`draft → pending_confirmation → confirmed_internal → reversed`. المسودة والانتظار ليسا تحصيلًا، والتأكيد الداخلي لا يثبت وصول البنك. التوزيع يقبل سندًا مؤكدًا وفاتورة صادرة للعميل والشركة والعملة نفسها، ولا يتجاوز المتاح أو الرصيد. العكس يعكس جميع التوزيعات النشطة ويرجع أرصدة الفواتير والسند في عملية Local متسقة؛ عقد Supabase يتطلب RPC وقفل صفوف.
