# نطاق المرحلة العاشرة

المرحلة توسع Production Jobs والمخزون القائمين إلى دورة إنتاج حسب المشروع: profiles، BOM، Routing، Work Centers، Orders، MRP محدود، Job Cards، Quality، Completion، Scrap/Rework، Downtime، Subcontracting، Capacity، Operational Costing والطباعة. خارج النطاق: GL، Journal Entries، WIP/Production Accounting، Payroll، AP، Supplier Payments، APS، Finite Optimization، MRP II، IoT/SCADA، Barcode hardware والنشر الإنتاجي.
