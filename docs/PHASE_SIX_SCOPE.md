# نطاق المرحلة السادسة

تبني المرحلة فوق Commit المرحلة الخامسة المنشور `ca79ead`. أضيفت جاهزية الفوترة، الفواتير الداخلية، الموافقات، سندات القبض، التوزيع، Credit/Debit Notes، Aging، كشف الحركة، المتابعة، التصدير والطباعة. خارج النطاق: General Ledger، الموردون والمشتريات، التسوية البنكية، الدفع، Refund البنكي، الإرسال الخارجي، رفع الملفات الإنتاجي، أسعار الصرف، بوابة العميل، وأي تكامل ZATCA أو نشر إنتاجي.

كل بيانات Local Mode مصطنعة. لا تمثل حركة مالية أو مستندًا ضريبيًا حقيقيًا.
