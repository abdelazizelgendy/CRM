# الطباعة والتصدير

واجهة التقارير توفر HTML Print A4 ثنائي اللغة عبر Browser Print، مع تكرار رأس الجدول ومنع قطع الصفوف وإخفاء الأزرار وWatermark داخلي. التكلفة تختفي حسب الصلاحية، ويظهر تنبيه «تقييم تشغيلي غير محاسبي».

لا PDF خادمي أو توقيع إلكتروني أو ختم أو QR رسمي أو مستند ضريبي أو سند قانوني. تصدير CSV يحمي من Formula Injection.
