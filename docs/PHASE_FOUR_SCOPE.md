# المرحلة الرابعة — المبيعات وعروض الأسعار

## المنفذ فعليًا

- لوحة مبيعات ومسارات مستقلة للطلبات، دليل الخدمات والباقات، عروض الأسعار، الموافقات، القوالب، وتفاصيل السجلات.
- Local Adapter كامل يعمل دون Supabase، مع بيانات تجريبية لشركتين وعزل صارم داخل Repository.
- إنشاء طلب يدوي أو من محادثة مع منع تكرار المحادثة، وترقيم `RFQ-YYYY-#####`.
- إنشاء عرض متعدد البنود مع الإضافة والنسخ والحذف وإعادة الترتيب، وترقيم `QUO-YYYY-#####-V#`، وحفظ Snapshot مستقل للعميل والشركة والبنود والشروط والقالب.
- حساب الخصم والضريبة والرسوم والبنود الاختيارية والتقريب باستخدام Minor Units وBigInt.
- دورة المسودة والمراجعة والتعديل والاعتماد والإصدار الجديد والإرسال والرد التجريبي.
- معاينة HTML/Print بقياس A4 وRTL/LTR وعلامة DEMO/DRAFT وجدول قابل لتكرار رأسه عند الطباعة.
- Types وZod وRepository Interface وSupabase Stub وMigration 005 غير مطبقة وSeed تجريبي لشركتين.
- بحث وفلاتر كاملة محفوظة في URL، Pagination وترتيب، وحالات Empty/Error، وتصدير CSV آمن محكوم بالصلاحية.
- راجع `PHASE_FOUR_GAP_ANALYSIS.md` لحالة الاستكمال والفحص البصري.

## الحدود المتعمدة

لا يوجد اتصال حقيقي ببريد أو WhatsApp، ولا PDF Server-Side، ولا بوابة عامة أو توقيع قانوني، ولا تطبيق Migration، ولا عقود أو فواتير أو دفع. المخرجات المسماة إرسالًا وقبولًا تحمل علامة Demo ولا تمثل إجراءً خارجيًا أو قانونيًا.

## التشغيل المحلي

اضبط `DATA_PROVIDER=local`، ثم نفّذ `npm ci` و`npm run dev` وافتح `/dashboard/sales`. يحظر Local Provider في Production ما لم يُضبط مفتاح الاختبار الصريح؛ لا يستخدم هذا المفتاح في نشر حقيقي.
