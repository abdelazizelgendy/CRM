# دورة المورد

`draft → pending_review → approved` مع `rejected` و`suspended` و`archived`. لا يستخدم المورد في RFQ أو أمر شراء أو فاتورة داخلية قبل الاعتماد.

كشف التكرار داخل الشركة يعتمد الاسم/الرقم الضريبي أو البريد. الإيقاف قرار مستقل مبرر، ولا يحدث تلقائيًا بسبب التقييم. تعديل تقييم معتمد يتطلب Revision.
