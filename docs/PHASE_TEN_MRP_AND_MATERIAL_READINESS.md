# MRP وجاهزية المواد

المعادلة: `Net = max(0, Gross + Safety + Existing Reserved - Usable On-hand - Eligible Open Supply)`. Gross يأتي من BOM explosion مع scrap وfixed quantities. Quarantine/Damaged/Expired لا تدخل Usable. كل requirement يحتفظ بـPegging للأمر والمشروع وWBS والمهمة. النتائج snapshots؛ لا تنشئ PO/RFQ/Release تلقائيًا ولا تمثل Forecast أو MRP II.
