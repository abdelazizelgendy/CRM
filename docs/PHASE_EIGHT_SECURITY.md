# أمن المرحلة الثامنة

- كل وصول Local يتحقق من المستخدم والشركة والصلاحية، وكل علاقة مشروع/مهمة تُراجع قبل الكتابة.
- Maker‑Checker للميثاق وBaseline والوقت والتقدم؛ Record Version للتزامن المتفائل؛ Idempotency لإنشاء المشروع.
- منع Dependency Cycles، تقدم خارج 0–100%، وقت سلبي/مكرر/>24 ساعة، وخفض تقدم معتمد بلا Reversal.
- معدلات العمل والتكلفة والربحية تُحجب في Snapshot. لا `service_role` في المتصفح ولا بيانات بنكية/رواتب/عملاء حقيقية جديدة.
- Migration تفعل RLS للقراءة فقط. سياسات الكتابة وRPCs ذرية غير منفذة حتى اختبار Supabase؛ العقد الحالي يرفض التشغيل.
