# نطاق المرحلة الثالثة

## المنفذ

- `/dashboard/inbox`: قائمة محادثات، بحث وفلاتر، رسائل، مسودات محفوظة أثناء التنقل، رد تجريبي idempotent، ملاحظات داخلية، حالة، أولوية، إسناد، لوحة العميل وربط Lead.
- `/dashboard/inbox/templates`: قوالب عربية/إنجليزية ومتغيرات آمنة.
- `/dashboard/inbox/settings`: حالات القنوات وSLA والإسناد التجريبي.
- مؤشرات محسوبة من Seed: الجديد، المفتوح، غير المقروء، التجاوز، متوسطات الرد والحل، والالتزام.
- 13 نموذج قناة موحد وعقود TypeScript وLocal Repository وSupabase Stub.

## المؤجل عمدًا

الاتصال الحقيقي بواتساب وMeta وTelegram والبريد وLinkedIn وGoogle Business، Webhooks، Push، الذكاء الاصطناعي، وتطبيق Migration على Supabase. لا تعرض أي قناة باعتبارها متصلة.
