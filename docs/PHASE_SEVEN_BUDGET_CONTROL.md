# ضبط الميزانية

خط الأساس المعتمد Snapshot غير قابل للتعديل. التغيير إصدار جديد بسبب موثق وموافقة منفصلة. كل سطر يرتبط Cost Code، والعملة لا تتغير داخل الميزانية.

طلب الشراء يفحص المتاح قبل الإنشاء. التجاوز يحتاج صلاحية Override وسببًا، ويولد تنبيهًا. عقود Supabase المستقبلية تحتاج Row Lock وRPC لحجز الميزانية وإطلاقها ذريًا.
