# المنتجات وBOM

Inventory Item هو المرجع الأساسي ولا يوجد Item Master مكرر. Production Profile يضيف Make/Buy/Subcontract، batch، lead time وscrap. BOM تدعم lifecycle وإصدارًا فعالًا وmulti-level explosion بحد عمق 20 وكشف دورة، fixed/per-output quantities وscrap allowance. Released revisions غير قابلة للتعديل، والأمر يحفظ snapshot لا يتغير بتغير المصدر.
