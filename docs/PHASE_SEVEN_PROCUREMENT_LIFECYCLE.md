# دورة المشتريات

طلب شراء مرتبط بمشروع وعقد وWork Order وميزانية → موافقة → RFQ داخلي → عروض موردين مع عملة واحدة → مقارنة فنية ومالية → ترسية كاملة أو جزئية → أمر شراء مرة واحدة.

تجاوز الميزانية يرفض افتراضيًا، ويحتاج `procurement.override_budget` وسببًا موثقًا. RFQ والإصدار داخليان ولا يثبتان إرسالًا خارجيًا.
