# الموافقات والصلاحيات

أضيفت صلاحيات `inventory.*` المذكورة في نطاق المرحلة. Owner يمتلكها في Local Seed، وInventory Manager يدير الدورة التشغيلية، وWarehouse Keeper ينشئ/يلتقط/يرحل ضمن نطاقه دون رؤية التقييم، وFinance/Cost Controller يرى التكلفة ويعتمد التسويات/Reversal، وViewer للقراءة فقط.

Maker‑Checker يمنع مقدم الطلب من اعتماد عمله في نقاط الاعتماد. لا يستطيع Warehouse Keeper تعديل Snapshot التكلفة أو منح نفسه صلاحيات.
