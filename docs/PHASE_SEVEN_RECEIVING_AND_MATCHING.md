# الاستلام والمطابقة

الاستلام يقبل كمية جزئية أو كاملة من أمر شراء صادر، يمنع تجاوز المتبقي، ويسجل الجودة والمستلم والموافقة والعكس بحركة مقابلة. لا ينشئ مخزونًا أو حركة مستودع.

2-Way يقارن PO بالفاتورة. 3-Way يقارن PO والاستلام والفاتورة. سياسة مركزية تتحكم في سماحية السعر والكمية والتقريب. اختلاف الشركة أو المورد أو العملة أو تجاوز المستلم يفشل المطابقة.
