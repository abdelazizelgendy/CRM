# Aging وكشف حركة العميل

الفئات: غير مستحق، 1–30، 31–60، 61–90، وأكثر من 90 يومًا، استنادًا إلى due date والرصيد المفتوح في As Of. العملات منفصلة. كشف الحركة يجمع الفواتير الصادرة والتعديلات الصادرة والتوزيعات النشطة ويحسب رصيدًا متحركًا.

Local Mode لا يملك event ledger تاريخيًا كاملًا أو Opening Balance أو General Ledger؛ لذلك التقرير والكشف تشغيليان ومحدودان بأول حركة متاحة، وليسا كشف حساب محاسبيًا معتمدًا.
