# موافقات المرحلة السابعة

مراكز القرار تغطي اعتماد المورد والميزانية وطلب الشراء والمقارنة وأمر الشراء والاستلام وفاتورة المورد والمصروف. مقدم السجل لا يعتمد سجله في القرارات المحمية.

صلاحيات القوائم والمكونات لا تكفي وحدها؛ Repository يكرر القرار، وعقود Migration/RLS/RPC مطالبة بفرضه في قاعدة البيانات مستقبلًا.
