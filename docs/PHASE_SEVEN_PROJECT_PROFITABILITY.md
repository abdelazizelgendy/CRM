# ربحية العقود والمشاريع

المنظور التعاقدي يعرض قيمة العقد الحالية وميزانية التكلفة والهامش المخطط. التشغيلي يعرض فواتير العملاء الداخلية مقابل التكلفة التشغيلية. منظور الالتزام يعرض Actual وOpen Commitment وETC وEAC وهامش التوقع.

سياق التحصيل لا يسمى صافي تدفق نقدي لعدم وجود Supplier Payments. كل عملة منفصلة؛ عند اختلاف عملة العقد والتكلفة يعرض تحذير ولا يحسب هامشًا موحدًا.
